# ☕ Meus Projetos Java

Repositório dedicado ao desenvolvimento de habilidades em **Java, lógica de programação, algoritmos, estruturas de dados e Engenharia de Software**.

Este espaço reúne uma jornada prática de aprendizado composta por **60 mini projetos e desafios**, desenvolvidos progressivamente para consolidar fundamentos da programação e evoluir para a construção de aplicações com padrões profissionais.

## 🎯 Objetivo

Aplicar os conhecimentos adquiridos durante minha formação em programação, transformando conceitos teóricos em soluções práticas.

A proposta é desenvolver projetos com diferentes níveis de complexidade, explorando problemas reais e situações inspiradas no ambiente empresarial, especialmente nos contextos de gestão, compras, estoque, fornecedores e processos de negócio.

Mais do que escrever código, o objetivo é desenvolver raciocínio computacional, capacidade de resolução de problemas e boas práticas de desenvolvimento de software.

## 🏗️ Jornada de aprendizagem

A trilha está organizada em seis etapas, com evolução progressiva ao longo de 60 dias.

| Etapa | Dias | Conteúdo |
|---|---:|---|
| 1. Pensamento lógico | 01–10 | Algoritmos, variáveis, operadores e decisões |
| 2. Controle de fluxo | 11–20 | Condicionais, loops e validações |
| 3. Estruturas de dados | 21–30 | Arrays, listas, mapas e coleções |
| 4. Orientação a objetos | 31–40 | Classes, objetos, métodos, encapsulamento e herança |
| 5. Engenharia de Software | 41–50 | Exceções, arquivos, testes, Clean Code e segurança |
| 6. Projetos integradores | 51–60 | Aplicações, arquitetura e boas práticas |

## 📚 Organização dos projetos

Cada projeto terá seu próprio diretório e um arquivo `README.md` específico para contextualizar o desenvolvimento.

A documentação individual apresentará:

- **Contexto:** problema ou necessidade que motivou o projeto.
- **Objetivo:** o que a aplicação pretende resolver.
- **Escopo:** funcionalidades incluídas e limitações.
- **Requisitos:** requisitos funcionais e não funcionais.
- **Regras de negócio:** condições que orientam o funcionamento.
- **Conceitos aplicados:** fundamentos de Java utilizados.
- **Implementação:** organização e explicação da solução.
- **Critérios de aceitação:** condições para considerar o projeto concluído.
- **Testes:** cenários esperados, validações e casos de exceção.
- **Evolução:** melhorias e novos desafios técnicos.

Essa estrutura permitirá acompanhar não apenas o resultado final, mas também o raciocínio e as decisões técnicas por trás de cada implementação.
